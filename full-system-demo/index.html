Full System Run with Closed-Loop Pressure Control

The first run of Vivvity's gantry, clamp, and pressure system working together as one instrument.

What happens in the run

  1. Homes both axes
  2. Lowers the electrode block onto the microfluidic chip
  3. Locks the block to the chip with the electromagnetic clamp
  4. Pressurizes the chip with the syringe pump and holds the seal under pressure
  5. Releases the clamp and returns to its park position

Result

  • Closed-loop pressure hold: about 0.15 psi from setpoint
  • Complete cycle from homing to park
  • Adaptive feedforward reaches the target faster than a fixed-gain approach

Gantry and clamp

This subsystem sits inside the instrument's main liquid-handling gantry, so its vertical travel has to stay small to avoid the pipette toolhead. The electrode block also has to land flat and in the same place every cycle.

I used a dual lead-screw motion system for the horizontal and vertical axes. Lead screws are self-locking, so once in position they hold the clamp load mechanically, without the motor drawing current or fighting the load. The system stays clamped under pressure for the whole run, so this keeps it from drifting or overheating a driver.

Closed-loop pressure control

The syringe pump drives fluid through the chip during a run. I built both the sensing and the control loop for it.

Sensing. Pressure is read from a Honeywell MPRLS sensor through a custom I²C interface I wrote into the Marlin firmware (C++). The sensor reads absolute pressure, so the firmware tares it at the start of a session to get a gauge reading.

Control. The syringe pump is a stepper on its own axis. It homes with a pressure headroom offset, so it can start building pressure right away. Reaching a target quickly and holding it precisely need different behavior, so the controller has three phases:

  • Fast phase: an adaptive feedforward estimate closes most of the distance to the setpoint in one move
  • Fine phase: closes the remaining gap more slowly
  • Hold phase: proportional control with a small anti-stiction dither, which keeps the plunger from sticking and then jumping past the target
